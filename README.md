## 🚀 Featured Project

### 🛒 Redux Cart – E-commerce Application

A responsive shopping application built using React and Redux Toolkit, demonstrating practical frontend architecture and centralized state management.

**Key Features**
- Product listing and product details.
- Add, remove and update cart quantities.
- Redux Toolkit for centralized cart management.
- Memoized selectors for derived cart calculations.
- Persistent cart and theme preferences using Local Storage.
- Light and dark theme support.
- Lazy-loaded routes using React Router.
- Responsive user interface.

**Tech Stack:** React.js · Redux Toolkit · JavaScript · React Router · Vite · CSS3
